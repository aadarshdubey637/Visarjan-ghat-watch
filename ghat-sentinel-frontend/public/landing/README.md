# Landing page images

The landing page reads its photographs from `src/lib/landing-images.ts`.
To add more pictures: copy the files into `public/` (or this folder), then add an entry
(`src`, `alt`, `caption`) to that list. Use photographs you have the right to use, and keep captions honest:
the project's photographs are illustrative and are not identified as specific ghats.
Recommended: landscape, at least 1600 px wide, under 600 KB each.
